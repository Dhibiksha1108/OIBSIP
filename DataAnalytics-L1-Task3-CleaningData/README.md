## Objective

The objective of this project is to demonstrate professional data cleaning and preprocessing techniques by transforming a deliberately messy dataset into a clean and analysis-ready dataset.

## Dataset

The project uses an animal observation dataset containing information such as animal type, country, weight, body length, gender, geographic coordinates, animal name, observation date, and data compiler.

## Data Cleaning Process

The following data cleaning techniques were performed:

- Generated a data quality report
- Identified and handled missing values
- Detected and removed duplicate records
- Standardized inconsistent categorical values
- Converted dates to datetime format
- Corrected numerical and categorical data types
- Detected potential outliers using the IQR method
- Identified and handled logically invalid numerical values
- Performed final data validation
- Compared data quality before and after cleaning
