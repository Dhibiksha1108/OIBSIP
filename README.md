# House Price Prediction using Linear Regression

## Project Overview

This project focuses on predicting house sale prices using a Linear Regression model. The project uses the Kaggle House Prices dataset and demonstrates the complete machine learning workflow from data exploration and preprocessing to model training and evaluation.

## Objective

To build a Linear Regression model that predicts house prices based on selected housing features.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Features Used

- OverallQual
- GrLivArea
- GarageCars
- TotalBsmtSF
- FullBath
- YearBuilt

## Workflow

1. Loaded and explored the dataset
2. Checked for missing values
3. Selected relevant features
4. Handled missing numerical values using median imputation
5. Split the dataset into training and testing sets
6. Trained a Linear Regression model
7. Generated house price predictions
8. Evaluated the model using MAE, MSE, RMSE, and R² Score
9. Visualized actual vs predicted prices
10. Analyzed feature coefficients
11. Saved the trained model
12. Tested the model with sample house data

## Dataset

The dataset used is the **House Prices – Advanced Regression Techniques** dataset from Kaggle.

## Result

The trained Linear Regression model successfully predicts house sale prices using the selected housing features. Model performance is evaluated using standard regression metrics and visualizations.
